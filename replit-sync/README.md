# AbanoupAi independent console sync

This folder is a reference sync from the Replit-built independent console. The console is the runnable artifact; this folder is intentionally additive and does not replace the existing Lovable app.

The capability catalog is in `assistant-capabilities.json`. No API keys, Lovable gateway dependency, or external write operation is included. Supabase and Cloudflare were inspected only; no schema or resource mutation was performed.

The source snapshot below is provided so the existing repository can adopt the contract and supervised behavior when desired.
